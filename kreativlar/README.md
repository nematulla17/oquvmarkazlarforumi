# Reklama kreativlari

- `yangi/` — yangi video yoki rasmni shu yerga tashlang. Claude uni Ads Manager'ga yuklaydi.
- `yuklangan/` — yuklangan fayllar shu yerga ko‘chiriladi (video ID bilan).

Formatlar: 9:16 (1080×1920) — Reels/Stories, 1:1 (1080×1080) — lenta. MP4, ≤ 4 GB, 5–60 soniya.
Fayl nomida mazmunini yozing, masalan `silver-stend-9x16.mp4` — e’lon nomi shundan olinadi.

Bu papkadagi media gitga kirmaydi (.gitignore).
